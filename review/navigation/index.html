This is an actual stationary device recording: the user starts navigation from a ready route preview, navigation displays an active maneuver, the app moves to the background, then the user returns, stops navigation, and returns home.

Map, address, unrelated notification, and launcher areas are hidden to protect the tester's precise location and personal information. Black intervals and captions identify privacy edits; no app interface was generated or substituted. Audio is omitted.

A separate device check confirmed NavigationLocationService was a foreground service while navigation was active, including after the app moved to the background. The service stops when navigation is stopped. This is a stationary functionality demonstration, not a moving-road test.

The location foreground service is used only for user-initiated navigation so location updates and guidance can continue while another app is in use. The user can stop navigation in the app. Android notification visibility depends on OS permission settings; active foreground services are also managed by Android's Task Manager.
