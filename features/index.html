Features

Navigation features built around the road.

Unhinged Nav combines turn-by-turn navigation with voice control and selectable personality modes. The goal is simple: give drivers useful guidance with less need to reach for the phone.

Voice-first controls

Use voice commands for common navigation actions such as repeating an instruction, muting or unmuting guidance, re-centering the map, switching personality modes, confirming or canceling supported actions, and searching for useful stops along a route.

Route preview

Review a route before starting navigation so the trip is not a surprise. Step-by-step preview helps you understand upcoming turns and the overall route before you move.

Live GPS guidance

Turn-by-turn guidance, arrival detection, route tracking, and clear spoken instructions are the core navigation experience. Real-road testing is used to improve reliability before broad release.

Drive, Walk, and Bike

Choose the travel mode that matches the trip. Public transit is not part of the current product scope.

Personality modes

Choose Codependent, Sarcastic, or Adult guidance. Adult Mode is optional and intended for users 18 and older.

Search that fits the trip

Search for destinations and useful categories such as coffee, gas, pharmacies, supermarkets, food, hotels, and other stops relevant to the route.

Beta access

Android testing comes first, with iPhone testing planned next. Join the First Wave to receive beta updates.
